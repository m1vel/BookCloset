# BookCloset

Читалка книг для Windows: библиотека с обложками и полками плюс читалка, которая открывает почти любой формат.

## Готовые файлы

| Файл | Что это |
|---|---|
| `dist/BookCloset-Setup-1.0.0.exe` | Установщик: ярлыки, выбор папки, ассоциации .epub/.fb2/.mobi/.djvu/.cbz/.pdf/.chm |
| `dist/BookCloset-Portable-1.0.0.exe` | Один файл без установки. Данные лежат рядом, в папке `BookCloset Data` |

Данные установленной версии хранятся в `%APPDATA%\BookCloset`: копии книг, обложки, заметки, статистика, настройки.

## Форматы

| Формат | Чем открывается |
|---|---|
| EPUB 2/3 (вкл. fixed layout), MOBI, AZW, AZW3/KF8, PRC | foliate-js |
| FB2, FB2.ZIP | foliate-js (кодировки UTF-8 и windows-1251) |
| TXT | автоопределение UTF-8/16, CP1251, KOI8-R, CP866; главы находятся сами |
| HTML, XHTML, MHT/MHTML, Markdown | свои конвертеры (скрипты из книг вырезаются) |
| DOCX, ODT, RTF, DOC (Word 97) | mammoth, свой ODT-парсер, rtf.js, word-extractor |
| PDF | pdf.js: текстовый слой, ссылки, оглавление |
| DjVu | DjVu.js в Web Worker, выделяемый текст |
| CBZ, CBR, CB7, CBT, ZIP/RAR/7Z, CHM | 7-Zip (WASM) |
| JPG/PNG/WEBP/GIF | как однокадровый комикс |
| LIT, LRF, SNB, TCR, PML… | через Calibre, если он установлен |

## Возможности

- Три темы интерфейса: «Бумага», «Полночь», «Стекло» (акрил Windows 11 и подсветка по обложке).
  Шесть цветов страницы. Русский и английский интерфейс.
- Постраничный режим с разворотом или прокрутка. Колонтитулы как в бумажной книге.
  Программные переносы слов (ru, en, de, fr, …). 11 шрифтов.
- PDF, DjVu и комиксы: лента, страница или разворот; масштаб Ctrl+колесо; режим манги справа налево.
- Чтение вслух (R или «Читать вслух отсюда» в меню выделения): голоса Windows, подсветка предложения и слова,
  автоматическое перелистывание, скорость 0.6–2.5×, выбор голоса для каждого языка, таймер сна.
- Автопрокрутка (S): плавная прокрутка в ленте или перелистывание по таймеру, пробел — пауза, +/− — скорость.
  Режим фокуса (F): интерфейс скрыт, линейка чтения затемняет всё, кроме текущих строк (↑/↓ — по строкам).
- Оглавление, полнотекстовый поиск, закладки, цветные выделения, заметки, всплывающие сноски,
  экспорт заметок в Markdown.
- Карточки цитат: выделите текст → «Карточка цитаты» — PNG в стилях «Бумага», «Ночь» и «Обложка»
  (размытая обложка книги), форматы 1:1, сторис 9:16 и 16:9, копирование в буфер или сохранение.
- Библиотека: «Продолжить чтение», сетка или список, коллекции, избранное, поиск, сортировка,
  drag & drop, карточка книги с редактированием.
- Обложки, аннотации и год издания из Open Library и Google Books: поиск для одной книги
  или «Найти недостающие обложки» для всей библиотеки (применяются только уверенные совпадения).
- Статистика: время за сегодня и за неделю, серия дней, скорость, цель на день, график за 30 дней,
  календарь чтения, самые читаемые книги.

- Словарь и карточки: «В словарь» в окне перевода сохраняет слово с предложением и книгой;
  повторение по интервальной схеме SM-2 (Снова / Трудно / Хорошо / Легко, клавиши 1–4), экспорт в Anki.

### Перевод выделенного текста

Выделите текст и нажмите «Перевести» (или `Ctrl+T`). Язык оригинала определяется сам. Язык перевода
выбирается прямо в карточке, а по умолчанию берётся из настроек. Если текст уже на языке перевода,
он переводится на английский.

| Сервис | Ключ | Особенности |
|---|---|---|
| Google Translate | не нужен | Для отдельных слов показывает словарь по частям речи, транскрипцию и озвучку |
| DeepL | свой | Учитывает абзац вокруг выделения |
| Yandex Translate | свой (Yandex Cloud) | — |
| Claude (Anthropic) | свой | Литературный перевод с учётом контекста и пояснениями к идиомам; модель выбирается (по умолчанию Opus 5.5) |
| OpenAI | свой | То же, модель задаётся вручную |

Ключи хранятся в `secrets.json`, зашифрованные средствами Windows (DPAPI), и в интерфейс не возвращаются.
Перевод можно сохранить в заметки, а двойной клик по слову может сразу показывать его перевод
(включается в настройках).

Горячие клавиши: `←/→`, `Space`, `PgUp/PgDn` листают; `T` открывает оглавление; `Ctrl+F` ищет;
`Ctrl+B` ставит закладку; `Ctrl+T` переводит выделенное; `Ctrl +/−` меняет размер текста или масштаб; `F11` включает полный экран;
`Esc` возвращает назад.

## Разработка

```bash
npm install          # если Electron не распаковался (бывает в папках OneDrive), см. ниже
npm run dev          # приложение с горячей перезагрузкой
npm run typecheck
npm run dist         # установщик + portable в dist/
```

Тестовые книги в репозиторий не входят: часть из них — чужие файлы. Генератор `scripts/make_samples.py`
создаёт образцы из текстов в `samples/src/`.

Тесты с Playwright запускают окно невидимо, за пределами экрана:

```bash
python scripts/make_samples.py          # тестовые книги во всех форматах → samples/
npm run build
node tests/run.mjs import-all --fresh   # импорт всех образцов
node tests/run.mjs open-formats         # открыть по книге каждого формата, скриншоты → tests/shots/
node tests/run.mjs reader-interact      # листание, оглавление, выделение, поиск, закладки
node tests/run.mjs paged                # PDF / DjVu / комиксы
node tests/run.mjs open-formats --exe   # то же на собранном dist/win-unpacked/BookCloset.exe
```

Если `npm install` не распаковал Electron: распакуйте архив из `%LOCALAPPDATA%\electron\Cache\…\electron-v38.8.6-win32-x64.zip`
в `node_modules/electron/dist` и создайте файл `node_modules/electron/path.txt` с текстом `electron.exe`.

## Устройство

```
src/main       — Node: библиотека (JSON), импорт и дедуп по SHA-1, протоколы app:// и bc://, 7-Zip, Calibre, окно
src/preload    — мост window.bc
src/renderer   — React-интерфейс
  formats/     — определение формата и конвертеры, всё сводится к двум видам источников:
                 reflow (книга foliate-js) или paged (PDF/DjVu/изображения)
  engines/     — ReflowEngine (foliate-js) и PagedEngine (свой виртуализированный просмотрщик)
  views/       — библиотека, читалка, статистика, настройки, заметки
  translation/ — перевод выделенного: определение языка, провайдеры (сеть и ключи — в src/main/translate.ts)
  vendor/foliate-js — с двумя патчами: CFI не учитывает мягкие переносы; заголовки FB2 склеиваются через точку
```

# BookCloset — план разработки

Десктоп-читалка для Windows: библиотека + читалка, все популярные (и редкие) форматы книг,
три переключаемые темы оформления, RU/EN. Сборка: установщик (NSIS) + portable `.exe`.

## Стек

| Слой | Технология | Почему |
|---|---|---|
| Оболочка | Electron 38+ (Chromium + Node) | Rust/.NET на машине нет; Chromium лучше всех рендерит HTML/XHTML-книги |
| Сборка | electron-vite + Vite + TypeScript | быстрый dev, HMR, отдельные бандлы main/preload/renderer |
| UI | React 19 + Zustand, чистый CSS на токенах | три темы = три набора CSS-переменных |
| Иконки | Phosphor Icons | одна линейка, единая толщина штриха |
| Шрифты | Literata, PT Serif, Lora, Source Serif 4, Cormorant Garamond, Inter, Manrope (локально, @fontsource) | кириллица во всех, работают офлайн |
| Упаковка | electron-builder: `nsis` + `portable` | ассоциации файлов, ярлыки, portable хранит данные рядом с exe |
| Тесты/скриншоты | Playwright (`_electron`) | запуск реального приложения, скриншоты каждого экрана и формата |

## Форматы и способ отображения

Два движка отображения:

1. **Reflow-движок** (foliate-js): текст перетекает, есть постраничный и прокручиваемый режимы, свои шрифты и поля,
   поиск, CFI-якоря для выделений.
2. **Page-движок** (свой): фиксированные страницы, то есть PDF, DjVu и комиксы. Режимы: страница, разворот,
   непрерывная прокрутка. Масштаб, текстовый слой для выделения и поиска, режим манги (справа налево).

| Формат | Парсер | Движок |
|---|---|---|
| EPUB 2/3 (вкл. fixed-layout) | foliate-js `epub.js` | reflow |
| MOBI, AZW, AZW3/KF8, PRC, PDB(PalmDoc) | foliate-js `mobi.js` | reflow |
| FB2, FB2.ZIP/FBZ | foliate-js `fb2.js` (+ проверка кодировки windows-1251) | reflow |
| TXT | детект кодировки (UTF-8/16, CP1251, KOI8-R, CP866) → главы по эвристикам | reflow (синтетическая книга) |
| HTML/HTM/XHTML, MHT/MHTML | DOMParser, санитайз, картинки → data-URI, деление по h1/h2 | reflow |
| Markdown | marked | reflow |
| RTF | rtf.js (вкл. WMF/EMF-картинки) | reflow |
| DOCX | mammoth (картинки base64) | reflow |
| DOC (Word 97-2003) | word-extractor (текст) | reflow |
| ODT | свой конвертер content.xml → HTML (+ Pictures/) | reflow |
| CHM | 7z-wasm: распаковка → .hhc оглавление → HTML-страницы | reflow |
| ZIP | распаковка, поиск книги внутри, рекурсивное открытие | любой |
| PDF | pdf.js (pdfjs-dist): canvas + текстовый слой | page |
| DjVu | DjVu.js (декодер в Web Worker), текстовые зоны | page |
| CBZ / CBR / CB7 / CBT | 7z-wasm (zip/rar/7z/tar) → изображения, ComicInfo.xml | page |
| Изображения (jpg/png/webp/gif) | как однокадровый комикс | page |
| Прочее (LIT, LRF, SNB, TCR…) | если установлен Calibre → `ebook-convert` в EPUB | reflow |

## Архитектура

```
main (Node)                         renderer (React)
 ├ library.json (книги, прогресс)    ├ views: Library / Reader / Stats / Settings
 ├ annotations/<id>.json            ├ formats/: detect → converters → BookSource
 ├ stats.json (сессии чтения)        ├ engines/reflow (foliate-view)
 ├ books/<id>.<ext> (копии)          ├ engines/pages (PDF/DjVu/Comic)
 ├ covers/<id>.webp                  ├ store/ (zustand)
 ├ cache/<id>/ (распакованные архивы)└ i18n/ (ru, en)
 ├ протокол bc:// (файлы книг/обложек/кэша)
 └ 7z-wasm, Calibre-мост, ассоциации файлов
```

* `BookSource = { kind: 'reflow', book } | { kind: 'pages', doc }`: любой формат сводится к одному из двух.
* Позиция чтения: CFI для reflow, `{page, offset}` для page-движка.
* Выделения: CFI-диапазон (reflow) или страница + прямоугольники (page).
* **Задел под перевод**: `TranslationProvider` (detect + translate), реестр провайдеров
  (бесплатный онлайн / DeepL / Yandex / Claude / OpenAI), кнопка в меню выделения за фича-флагом.

## Темы

* **Paper** (по умолчанию): кремовая бумага, коричневый переплёт и янтарь, засечки Cormorant/Literata.
* **Midnight**: тёмный минимализм, интерфейс прячется при чтении.
* **Glass**: стекло и глубина, фон размыт по обложке текущей книги.
* Отдельно **цвета страницы**: Белая / Сепия / Бумага / Серая / Ночь / OLED.
